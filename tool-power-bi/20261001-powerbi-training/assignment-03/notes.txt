Example (minimal tidy step):

let
    Source = Customers,
    #"Selected Columns" = Table.SelectColumns(
        Source,
        {"Customer ID", "Customer Name", "Email", "Segment", "Region", "City", "Country"}
    ),
    #"Renamed Columns" = Table.RenameColumns(
        #"Selected Columns",
        {{"Email", "Customer Email"}}
    ),
    #"Distinct Customers" = Table.Distinct(#"Renamed Columns", {"Customer ID"})
in
    #"Distinct Customers"

2. Required calculated columns in Power Query (FactSales)
In your FactSales query, after you have:

Quantity (number),
Unit Price (number),
Discount % (number, e.g. 10 = 10%),
Tax Rate (number, e.g. 5 = 5%),
Shipping Fee (number),
Order Date, Ship Date (date),
add these steps (you already have most of them; this is the clean, minimal version).

Replace PreviousStep with your last step name.

// 1. Discount Rate (as decimal)
#"Added Discount Rate" = Table.AddColumn(
    PreviousStep,
    "Discount Rate",
    each if [Discount %] = null then null else [Discount %] / 100,
    type number
),

// 2. Tax Rate (as decimal)
#"Added Tax Rate Decimal" = Table.AddColumn(
    #"Added Discount Rate",
    "Tax Rate Decimal",
    each if [Tax Rate] = null then null else [Tax Rate] / 100,
    type number
),

// 3. Gross Sales = Quantity × Unit Price
#"Added Gross Sales" = Table.AddColumn(
    #"Added Tax Rate Decimal",
    "Gross Sales",
    each if [Quantity] = null or [Unit Price] = null then null else [Quantity] * [Unit Price],
    type number
),

// 4. Discount Amount = Gross Sales × Discount Rate
#"Added Discount Amount" = Table.AddColumn(
    #"Added Gross Sales",
    "Discount Amount",
    each if [Gross Sales] = null or [Discount Rate] = null then null else [Gross Sales] * [Discount Rate],
    type number
),

// 5. Net Sales = Gross Sales − Discount Amount
#"Added Net Sales" = Table.AddColumn(
    #"Added Discount Amount",
    "Net Sales",
    each if [Gross Sales] = null then null else [Gross Sales] - (if [Discount Amount] = null then 0 else [Discount Amount]),
    type number
),

// 6. Tax Amount = Net Sales × Tax Rate
#"Added Tax Amount" = Table.AddColumn(
    #"Added Net Sales",
    "Tax Amount",
    each if [Net Sales] = null or [Tax Rate Decimal] = null then null else [Net Sales] * [Tax Rate Decimal],
    type number
),

// 7. Invoice Amount = Net Sales + Tax Amount + Shipping Fee
#"Added Invoice Amount" = Table.AddColumn(
    #"Added Tax Amount",
    "Invoice Amount",
    each 
        if [Net Sales] = null then null 
        else [Net Sales]
             + (if [Tax Amount] = null then 0 else [Tax Amount])
             + (if [Shipping Fee] = null then 0 else [Shipping Fee]),
    type number
),

// 8. Shipping Days = Ship Date − Order Date
#"Added Shipping Days" = Table.AddColumn(
    #"Added Invoice Amount",
    "Shipping Days",
    each 
        if [Ship Date] = null or [Order Date] = null then null
        else Duration.Days([Ship Date] - [Order Date]),
    Int64.Type
)
3. Additional columns in FactSales
3.1 Order year, month, year-month, financial quarter
Add these after the Shipping Days step:

// Order Year
#"Added Order Year" = Table.AddColumn(
    #"Added Shipping Days",
    "Order Year",
    each if [Order Date] = null then null else Date.Year([Order Date]),
    Int64.Type
),

// Order Month (numeric)
#"Added Order Month" = Table.AddColumn(
    #"Added Order Year",
    "Order Month",
    each if [Order Date] = null then null else Date.Month([Order Date]),
    Int64.Type
),

// Year-Month (text like 2024-10)
#"Added YearMonth" = Table.AddColumn(
    #"Added Order Month",
    "Year-month",
    each if [Order Date] = null then null else Date.ToText([Order Date], "yyyy-MM"),
    type text
),

// Financial quarter (assume same as calendar quarter)
#"Added Financial Quarter" = Table.AddColumn(
    #"Added YearMonth",
    "Financial quarter",
    each if [Order Date] = null then null else "Q" & Number.ToText(Date.QuarterOfYear([Order Date])),
    type text
)
If your financial year starts in a different month, this can be adjusted, but for the assignment calendar quarters are usually acceptable.

3.2 Promotion-valid flag
To be fully correct, you should compare Order Date to DimPromotion[Start Date] and [End Date].

Simplest approach in Power Query:

Merge FactSales with DimPromotion on Promotion Code to bring Start Date and End Date into FactSales (or keep this as a separate step/query).
Then:
#"Added Promotion Valid Flag" = Table.AddColumn(
    PreviousStep,
    "Promotion-valid flag",
    each 
        if [Promotion Code] = null or [Promotion Code] = "" then "No promotion"
        else if [Order Date] = null or [Start Date] = null or [End Date] = null then "Unknown"
        else if [Order Date] >= [Start Date] and [Order Date] <= [End Date] then "Valid"
        else "Not valid",
    type text
)
If you don’t want to merge, you can keep a simple placeholder version for the assignment: “Has promotion” vs “No promotion”.

3.3 Late-shipment flag
Define your business rule. Common for training: late if Shipping Days > 5.

#"Added Late Shipment Flag" = Table.AddColumn(
    PreviousStep,
    "Late-shipment flag",
    each 
        if [Shipping Days] = null then "Unknown"
        else if [Shipping Days] > 5 then "Late"
        else "On time",
    type text
)
3.4 Data-quality status
You already have multiple *Status columns (Order Date Status, Ship Date Status, Quantity Status, Product ID Status, etc.). Combine them into a single summarised status:

#"Added Data-quality Status" = Table.AddColumn(
    PreviousStep,
    "Data-quality status",
    each 
        if [Order Date Status] <> "Valid" or [Ship Date Status] <> "Valid" then "Date issue"
        else if [Quantity Status] <> "Valid" then "Quantity issue"
        else if [Product ID Status] <> "Present" then "Missing product"
        else if [Duplicate OrderLine Status] = "Duplicate" then "Duplicate order line"
        else if [Exact Duplicate Status] = "Exact Duplicate" then "Exact duplicate"
        else "OK",
    type text
)
You can adjust the priority/order of checks to match your preference.
