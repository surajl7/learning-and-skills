Power BI Data Transformation Assignment 2:

Objective: Load the provided files into Power BI and perform the required data transformations.

-- =======================================================================================

Task 1: Date Column Transformation
Import the assigned file into Power BI.
Change the order_date column to Date data type.
Identify and fix any conversion errors that occur.
Ensure no rows are removed while resolving errors.
Validate that all records are retained after transformation.

-- =======================================================================================

Task 2: Text Standardization
Review all text columns in the dataset.
Convert text values to a consistent Proper Case (Camel/Title Case) format.
Example:
john doe → John Doe
PRODUCT NAME → Product Name
Verify consistency across all applicable columns.

-- =======================================================================================

Task 3: Data Consolidation and Lookup
Append the January and February datasets into a single table.
Join/Merge the consolidated table with the Product table.
Fetch and populate the Product Name column from the Product table.
Validate record counts before and after the merge.

-- =======================================================================================

Expected Deliverables
Updated Power BI (.pbix) file.
Transformation steps documented in Power Query.

Validation summary including:
Record counts before and after transformations.
Any issues encountered and their resolution.
